# AssetHub 视觉美学重构 PRD (去“AI味”与高透光液态毛玻璃)

## 一、需求背景与目标

在初版现代视觉改造中，页面已初步具备毛玻璃与卡片质感，但存在两个影响高级感与工业级体验的核心问题：
1. **导航栏透光感不明显**：原导航栏背景不透明度高达 76%，且顶部背衬缺乏充足的光通量支撑，导致整体视觉过于厚重发白，在静态及滚动时均无法呈现通透折射的液态玻璃（Liquid Glass）效果；
2. **按钮存在强烈的“AI味”**：
   - 按钮前滥用表情图标（如 🚀、🕒、📂、📦、⚡、📋、🔍 等），显得低幼且像 AI 自动生成的 Demo 模板；
   - 按钮采用高饱和“AI 蓝”（`#4f46e5`、`#3b82f6`）和白底蓝字，界面颜色杂乱缺乏克制；
   - 缺乏现代高奢工效软件（如 Apple Developer、Linear、Raycast）纯净、笃定的黑白灰工业美学。

---

## 二、核心重构规范与标准

### 2.1 导航栏极致高透光（Extreme Translucent Liquid Glass）
- **透光率下调**：导航栏背景不透明度统一由 `0.76` 调降至 `0.38`（`rgba(255, 255, 255, 0.38)`）；
- **光线散射与高饱和折射**：
  - 滤镜增强至 `backdrop-filter: blur(28px) saturate(210%) contrast(102%)`；
  - 在页面顶层增加贯穿式流光背衬 `.nav-aurora-backdrop`（冰蓝与晶紫 96px 椭圆极光向四周柔和漫射）；
  - 动态呼吸光斑中心上提至 `-140px` 与 `-110px`，直接切过导航栏横贯轴线，使得静止状态下亦有水润流光穿透；
  - 滚动内容穿过导航栏时，文字与图像边缘呈现高保真磨砂流体透光。
- **物理反光双层边线**：
  - 顶部与内侧应用 `inset 0 1px 0 0 rgba(255, 255, 255, 0.95)` 纯白晶体高光反光；
  - 下沿配合超细浅灰色微边框与极微投影，呈现悬浮晶透玻璃板质感。

---

### 2.2 彻底去“AI味”，重构顶级黑白灰工效美学（Monochrome Ergonomics）
- **图标与 Emoji 全面净化**：
  - 移除分段控制器、主操作按钮、次级按钮、表格操作、弹窗按钮等所有位置的前置图标（彻底告别 🚀、⚡、📦、📋 等）；
  - 状态徽章去除 🟢、🟡、🔴 Emoji，升级为 5px 微实心圆点 + 低饱和灰调背景；
  - 拖拽卡片去除大号 📂 表情，重构为微米级纯几何线条托盘。
- **色彩与层级重构（拒绝 AI 蓝与蓝色文字）**：
  - **主操作按钮（Primary Button）**：
    - 底色：深空曜石黑（Deep Obsidian `#090d16`）；
    - 文字：纯白 `#ffffff`，字重 550，微收紧字间距；
    - 光影：微内发光线 `inset 0 1px 0 rgba(255, 255, 255, 0.2)`，hover 悬停平滑上浮，点击具备苹果物理弹簧回弹；
  - **次级操作按钮（Secondary Button）**：
    - 底色：晶透微冷白（Translucent White `rgba(255, 255, 255, 0.85)`）；
    - 文字：深炭黑（`#0f172a`），严禁蓝色文字；
    - 边框：超细石墨线（`rgba(0, 0, 0, 0.08)`），hover 边框略深；
  - **表格行操作动作**：
    - 纯文字微胶囊（`复制链接`、`代码`、`对比`、`移除`），纯白/微透基底，深灰字，hover 自动反转为曜石黑高亮。

## 四、验证标准

1. 浏览器打开页面，顶部导航栏能清晰看到柔和通透的光晕漫射；向上滚动页面时，卡片和列表文字从导航栏下穿过，形成强烈的磨砂液态玻璃透视效果；
2. 页面中无任何花哨 Emoji 图标装饰在按钮前，无廉价高饱和蓝色色块与蓝色文字；
3. 整体视觉达到 Apple iOS / macOS Tahoe 及高奢生产力软件的一致工业级美感。
