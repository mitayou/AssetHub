# AssetHub 前端组件化工程架构拆分与柔和质感按钮 PRD

## 一、需求背景与目标

在通过前期单页面验证并成功启动 Vite 项目后，现正式进入**工程化落地阶段**：
1. **主按钮视觉重塑**：弃用前期纯黑色块，换用视觉舒适、柔和耐看且富有光泽感的**暮山石墨黛蓝（Twilight Obsidian Mist）**，实现温润细腻的高端工效视感；
2. **纯化根目录入口**：清理前期用于独立静态演示的 1491 行内联单体代码，恢复为标准的 Vite SPA 入口 `index.html`；
3. **前端工程化组件解耦**：将原本堆叠在单个 `App.vue` 中的 1200 多行代码，按照职责解耦为：公共工具方法（`utils`）、组合式业务状态（`composables`）、细粒度功能组件（`components`）、设计系统令牌（`styles`）。

---

## 二、新版主按钮设计标准 (Twilight Obsidian Mist)

- **底色渐变**：`linear-gradient(180deg, #2c3444 0%, #1c2331 100%)`，融合温润墨黛与深空灰；
- **前景色**：微象牙晶白 `#f8fafc`（略柔于纯白，文字细腻耐看），字重 600；
- **微高光线**：顶部内发光微线 `inset 0 1px 0 0 rgba(255, 255, 255, 0.22)`；
- **柔和漫反射阴影**：`0 4px 14px -2px rgba(28, 35, 49, 0.22)`；
- **微交互**：悬停时背景温润微亮并轻柔上浮 1px，点击时具备苹果物理微回弹（`scale(0.98)`）。

## 三、工程化架构拆分目录规范

```
src/
├── config/apiConfig.ts         # 接口常量与 COS 存储桶配置
├── types/asset.ts              # 强类型定义
├── styles/
│   └── variables.css           # 全局高透光毛玻璃与暮山黛设计系统 Tokens
├── utils/
│   ├── format.ts               # 体积/时间格式化、代码模版生成
│   ├── clipboard.ts            # 剪贴板读写通用方法
│   ├── md5.ts                  # 原生 ArrayBuffer MD5 计算
│   └── zip.ts                  # ZIP 客户端内存平铺解压
├── composables/
│   ├── useToast.ts             # 全局轻提示状态
│   └── useAssetQueue.ts        # 上传队列、直传与弹窗交互状态
├── components/
│   ├── Navbar.vue              # 极致高透光极光毛玻璃导航栏
│   ├── Dropzone.vue            # 拖拽与剪贴板录入托盘
│   ├── QueueToolbar.vue        # 任务队列工具栏（新版柔和主按钮）
│   ├── QueueTable.vue          # 上传队列表格与行内操作
│   ├── TimelineList.vue        # 团队资产沉淀库时间轴看板
│   ├── CurtainModal.vue        # 1:1 像素级卷帘画质对比弹窗
│   ├── CodeModal.vue           # 交付代码生成器弹窗
│   └── Toast.vue               # 悬浮微提示组件
├── App.vue                     # 主界面容器（清晰协调器）
└── main.ts                     # Vite 挂载入口
```
