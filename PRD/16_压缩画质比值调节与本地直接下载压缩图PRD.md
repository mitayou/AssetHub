# 需求文档：压缩画质比值调节与本地直接下载压缩图

> **文档版本**：v1.0  
> **归档日期**：2026-09-21  
> **所属项目**：AssetHub 企业级前端静态资源效能工作台 (`e:\source\plugin\cosUpload`)  
> **核心目标**：
> 1. 解决模糊毛玻璃、平滑渐变图在强制 256 色 8-bit 量化下细节丢失和色阶断层问题，支持可调节的压缩画质比值（Quality 0.1~1.0）及“原画无损（毛玻璃专属）/ 极致均衡 / 极限体积”档位映射；
> 2. 彻底理清并规范 UPNG.js 与多格式压缩引擎边界（PNG 专属 vs JPG/WebP/GIF 各司其职）；
> 3. 新增本地直接下载压缩图能力（单项免上传秒级下载 + 批量打包/导出），无需上传 COS 即可直接享用本地压缩成果。

---

## 一、需求背景与业务痛点

### 1. 毛玻璃与大渐变图画质严重衰减痛点
* **现状**：上个迭代升级了 UPNG.js 8-bit 量化流水线后，普通 UI 图标实现了 -68% 的惊人体积缩减。但对于含有大面积高斯模糊、毛玻璃微磨砂以及平滑半透明渐变（Alpha 连续过渡）的切图，256 色调色板（Palette）由于槽位有限，无法承载数万种细微过渡色，强行量化导致出现肉眼可见的水波纹色阶（Color Banding）与边缘噪点，细节严重丢失。
* **诉求**：用户需要一个**压缩画质比值（Quality）**调节体系。在遇到毛玻璃、复杂渐变等对视觉质感要求极高时，能够灵活切换至**原画无损（Lossless 100%）**模式——保持 32-bit RGBA 完整色彩与柔和 Alpha 渐变，绝不进行调色板量化，仅交由 oxipng 进行无损 Deflate 深度瘦身，确保毛玻璃 100% 晶莹剔透。

### 2. 本地直接下载压缩图诉求
* **现状**：目前用户将切图加入队列后，本地极速测算出了体积节省，但用户必须点击“开始上传”将切图推送到腾讯云 COS 并入库后，才能获取 CDN 直链。
* **痛点**：在部分场景下（例如本地开发调试、临时优化图片、不希望占用线上 COS 存储桶），用户仅希望把本工具当做一个高性能的离线图片压缩神器，希望能够**在不上传的情况下直接下载压缩后的切图**。

## 二、详细技术方案设计

### 1. 压缩画质比值（Quality）与引擎映射策略

在前端暴露 3 个常用预设档位，并支持数值映射（0.1 ~ 1.0）：

| 画质档位 | 对应 Quality 比值 | PNG 策略 (UPNG + oxipng) | JPG / WebP 策略 | 适用切图场景 |
| :--- | :---: | :--- | :--- | :--- |
| 💎 **原画无损** | `1.0` (或 >= 0.98) | **完全无损编码** (`UPNG.encode(..., 0)`)，保留 32 位全彩 + 完整透明渐变，零色彩丢失；随后由 oxipng 进行极大熵 Deflate 优化（可减重 10%~30%） | Canvas 导出质量 1.0 | **毛玻璃、高斯模糊、大面积柔和渐变、高保真质感切图** |
| ⚡ **极致均衡**<br>*(默认推荐)* | `0.85` | **标准 8-bit 调色板量化** (`UPNG.encode(..., 256)`)，TinyPNG 同款原理，数据量直降 70%，并由 oxipng 二次优化 | Canvas 导出质量 0.85 | **常规 UI、图标、线框、扁平矢量插画、无毛玻璃切图** |
| 📦 **极限体积** | `0.70` | **轻量调色板量化** (`UPNG.encode(..., 128)`)，体积更小 | Canvas 导出质量 0.70 | 极端体积敏感场景、低带宽首屏切图 |

#### Worker 与主线程 Wasm 核心改造：
```typescript
// 智能色彩深度映射
let maxColors = 256;
if (quality >= 0.98) {
  maxColors = 0; // UPNG 源码规则：ps === 0 即为 32-bit RGBA Lossless 无损编码！
} else if (quality >= 0.8) {
  maxColors = 256;
} else if (quality >= 0.6) {
  maxColors = 128;
} else {
  maxColors = 64;
}

const pngArrayBuffer = UPNG.encode([imageData.data.buffer], width, height, maxColors);
```

### 2. 工具栏与队列画质联动交互
1. **QueueToolbar.vue**：在清空队列和上传按钮左侧，新增精致的 Apple 质感画质切换器：
   - 下拉选项包含：`💎 原画无损 (100%)`、`⚡ 极致均衡 (85%)`、`📦 极限体积 (70%)`；
   - 切换画质时，立即触发全局重新测算事件，队列中所有尚未上传的条目自动重新推入 Worker 线程池并发重算。
2. **队列项响应式**：每个条目独立记录当前压缩所用的 `quality`，支持未来单项扩展。

### 3. 本地直接下载功能实现
1. **下载助手工具类 `src/utils/download.ts`**：
   - 封装 `downloadBlob(blob: Blob, filename: string)`：基于内存 Blob URL 创建隐藏 `<a>` 标签并自动调用 `click()` 触发浏览器下载，随后自动释放 URL，防止内存泄漏；
   - 封装 `downloadQueueItem(item: IQueueItem)`：优先下载 `item.compressedFile`，若未压缩完成或保底则下载 `item.file`，保持原文件名不变。
2. **QueueTable.vue 操作列**：
   - 在每行操作区（“对比 / 移除”）前置增加 **“下载”** 动作按钮；
   - 点击立即将该项已压缩切图下载到本地，纯离线秒级完成，零网络流量消耗。
3. **QueueToolbar.vue 批量下载**：
   - 在工具栏增加 **“下载全部”** 辅助按钮；
   - 当队列中有完成压缩的切图时，用户可一键批量导出所有压缩切图。

## 四、验证计划

1. **毛玻璃画质验证**：
   - 将毛玻璃切图拖入工作台，选择“💎 原画无损 (100%)”，验证压缩后无水波纹色阶断层，半透明模糊质感完美保留，体积仍有 Deflate 优化瘦身；
   - 切换为“⚡ 极致均衡 (85%)”，验证常规图标可获得 -65%~-75% 极大瘦身。
2. **下载功能验证**：
   - 不点击“开始上传”，直接点击单行“下载”按钮，验证浏览器是否能正常弹出并保存压缩后的图片，文件名与格式完全吻合；
   - 点击工具栏“批量下载”，验证队列中所有项是否能批量下载完成。
