# 需求文档：测试沙箱 temp 目录隔离与生产自定义文件夹及工具栏重构

## 1. 业务背景与安全约束
1. **合规安全红线**：根据公司安全规范，代码中严禁开放 `DeleteObject` 物理删除能力，测试产生的临时切图由管理员在云端统一清空。
2. **测试沙箱路径隔离**：测试环境切图统一注入 `dsxcx/temp/` 前缀，与生产正式业务切图物理隔离，方便管理员一键批量清理而不会误伤业务资产。
3. **生产环境支持具体子目录**：线上业务需要支持将切图上传至团队指定的具体文件夹（如 `dsxcx/images/activity`、`dsxcx/images/goods` 等），支持预设常用目录与自定义输入。
4. **工具栏降噪与工效重构**：当前任务队列工具栏设置项（环境、画质、超时、下载、清空、上传）拥挤杂乱，需进行工效分层，分离“场景上下文”与“低频偏好设置”。

## 2. 详细设计

### 2.1 存储目录规范
- **测试沙箱 (`test-dskhd`)**：
  - 默认上传目录锁定为：`dsxcx/temp`；
  - 界面显示沙箱隔离提示，不可随意污染生产主目录。
- **生产线上 (`prod-wxapp`)**：
  - 基准根目录为 `dsxcx/images`；
  - 支持团队常用业务子目录快捷选择（如 `dsxcx/images`、`dsxcx/images/goods`、`dsxcx/images/activity`、`dsxcx/images/member` 等），并支持自由输入子路径。

### 2.2 工具栏视觉与交互优化（Apple 工效分层）
- **左侧场景上下文区**：
  - 任务队列计数；
  - 双轨制环境切换胶囊（测试沙箱 / 生产线上）；
  - 目标上传目录微面板（生产环境下提供常用子目录下拉与自定义输入，测试环境下展示锁定徽标 `dsxcx/temp`）。
- **右侧高能行动区**：
  - 压缩偏好设置（将低频的“画质”与“超时”收拢为带状态指示的精美 Popover 气泡菜单）；
  - 辅助动作：下载全部、清空队列；
  - 主动操作：开始上传（柔和暮山黛大按钮）。

### 2.3 移除前端云端删除
- 全面移除 `QueueTable.vue` 中的“删除”云端按钮及相关事件，前端恢复为纯粹的队列逻辑移除。
