# 23_任务队列工具栏动态状态感知与全部完成胶囊PRD

## 一、需求背景与目标

在原任务队列工具栏（`QueueToolbar.vue`）的标题区域旁，胶囊徽标原先固定显示 `{{ count }} 项待处理` 或 `共 {{ count }} 项`：
- 若显示“项待处理”，在批量上传完成（全部为 SUCCESS 态）后依然显示待处理，产生严重的逻辑与视觉错位；
- 若仅显示“共 X 项”，缺乏操作过程中的生命周期感知与进度反馈。

### 本次改造目标（方案 A）：
1. **动态智能状态感知**：
   - 徽标文本跟随队列条目生命周期动态演变：
     - 队列为空：显示 `0 项`；
     - 待上传就绪：显示 `共 X 项`；
     - 上传进行中：显示 `上传中 已完成数/总数`；
     - 全部上传成功：显示 `✓ 全部已完成 (X项)` 并呈现翡翠绿徽标；
     - 包含异常失败：显示 `X项失败 · Y项完成` 并呈现警示徽标。
2. **主按钮协同优化**：
   - 当队列全量条目均已上传入库且无新增待处理条目时，主上传按钮智能呈现 `已全部上传` 并置灰禁用，防止冗余点击。

## 二、详细设计与状态矩阵

| 队列状态 | 胶囊徽标文本 (`queuePillText`) | 徽标视觉样式 | 主操作按钮文案与状态 |
| :--- | :--- | :--- | :--- |
| **队列为空** (`totalCount === 0`) | `0 项` | 默认中性浅灰底 | 禁用 `开始上传` |
| **就绪待上传** (`pendingCount === totalCount`) | `共 X 项` | 默认中性浅灰底 | 激活 `开始上传` |
| **上传进行中** (`isUploading`) | `上传中 S/T` | 科技蓝微徽标 (`.uploading`) | 禁用 `正在上传...` |
| **全部上传成功** (`successCount === totalCount`) | `✓ 全部已完成 (X)` | 翡翠绿轻奢徽标 (`.success`) | 禁用 `已全部上传` |
| **部分失败** (`failCount > 0`) | `F项失败 · S项完成` | 柔和浅红徽标 (`.fail`) | 激活 `继续上传` / 重试 |
