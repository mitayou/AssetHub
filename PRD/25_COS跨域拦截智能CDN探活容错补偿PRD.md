# 25_COS跨域拦截智能CDN探活容错补偿PRD

## 一、背景与问题

在双轨制体系中，生产环境存储桶（`fastdfs-prod-1251596386`）为线上老桶，桶级别尚未配置 Web 端跨域规则（CORS）：
- 浏览器在向腾讯云发送 `PUT` 请求上传切图时，腾讯云服务端实际已成功处理并写入对象（落盘成功）；
- 但因腾讯云返回的 HTTP 响应头缺少 `Access-Control-Allow-Origin`，浏览器在客户端安全沙箱中阻断了响应读取并抛出 Network/CORS 异常；
- 导致前端 SDK 误判为上传失败（`item.status = 'FAIL'`）。

## 二、目标与方案

在运维在腾讯云控制台配置 CORS 之前，在前端代码层实现**免运维、智能探活容错补偿机制**：
1. **Image Ping 无视跨域阻断**：
   利用 HTML 原生 `<img>`（或 `new Image()`）在浏览器中不受跨域策略（SOP）限制的特性，对生成的线上 URL 进行轻量验真；
2. **多频探活重试（容忍回源延迟）**：
   在捕获到上传异常后，自动进行 3 次快速重试探活（间隔约 600~700ms），给腾讯云落盘及 CDN 回源预留足够时间；
3. **自动纠偏与无感放行**：
   只要探活通过，判定切图已在云端就绪，前端自动纠偏为 `SUCCESS` 成功态，返回正确的在线链接，使得后续流程（BFF 入库、复制链接、下载等）完全无缝畅通。
