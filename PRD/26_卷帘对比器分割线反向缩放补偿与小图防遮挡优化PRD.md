# 26_卷帘对比器分割线反向缩放补偿与小图防遮挡优化PRD

## 一、问题背景与痛点

在 `CurtainModal.vue`（1:1 卷帘画质对比弹窗）中：
1. **几何同频膨胀问题**：
   卷帘分割线（`.stage-divider`）与控制手柄（`.stage-handle-knob`）位于受 `scale` 缩放矩阵控制的舞台内部（`.stage-canvas`）。当用户放大画布（如放大至 300%~800%）查看大图片素级细节时，手柄和分割线一同被等比放大，圆盘变成上百像素的庞然大物，线条变粗数倍；
2. **小图核心区域严重遮挡问题**：
   若切图本身尺寸较小（如 32x32、48x48、64x64 等小图标），实心居中的手柄直接覆盖在图像中央，放大后更是遮盖了大部分画面，导致无法观察小图量化压缩质量。

---

## 二、优化设计（反向缩放补偿 + 幽灵避让）

### 1. 反向缩放补偿（Inverse Scale Compensation）
- 计算响应式倒数 `invScale = 1 / scale`，通过 CSS 变量 `--inv-scale` 注入；
- **分割线**：利用 `scaleX(var(--inv-scale))`，无论画布放大至何种倍率，分割线在屏幕上的显示宽度恒定为 1.5px~2px 锐利细线；
- **手柄**：利用 `scale(var(--inv-scale))`，在任何缩放比例下，手柄在视口中的物理直径恒定保持为 26px，绝不膨胀变形。

### 2. 全线感应拖拽与高透质感
- **整线感应**：为中线增加左右各 12px 的透明感应区（`::before`），用户在分割线的任意高度均可随意按住拖拽，无需必须点击正中心手柄；
- **毛玻璃微通透材质**：手柄背景改为 `rgba(15, 23, 42, 0.72) + backdrop-filter: blur(8px)`，呈现优雅高奢半透微光，透出底层微弱图像轮廓；
- **拖拽幽灵避让态（Ghost Mode）**：当拖拽中线时，手柄自动降为 `opacity: 0.25`，将 100% 视觉焦点还给左右两边的对比切图，杜绝遮挡。
