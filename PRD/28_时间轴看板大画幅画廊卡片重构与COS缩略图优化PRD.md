# 28_时间轴看板大画幅画廊卡片重构与COS缩略图优化PRD

## 一、需求背景与目标

在原“团队资产库 & 时间轴看板”（`TimelineList.vue`）中，切图以 48x48 的横向条目形式展示：
1. **缩略图过小，查找不直观**：在海量资产中定位特定切图时，48px 小图难以辨认细节与图形轮廓；
2. **视觉重心颠倒**：切图资产库的核心诉求是“看图找图”，应以大画幅图片为主体视觉，文件名、体积与上传人为辅助信息；
3. **带宽与性能隐患**：随着切图资产增多，直接加载原图会消耗巨大的网络带宽，急需集成腾讯云 COS/数据万象的轻量缩略图能力。

### 本次改造目标：
1. **重构为以大图为主的画廊网格卡片（Gallery Grid Card）**：
   - 将缩略图由 48px 小方块升级为 **200px 级大画幅视觉舞台**（高度 140px，面积扩大 8~10 倍），图片成为第一视觉焦点；
   - 包含经典透明棋盘格底纹、完整保持宽高比居中对齐、悬浮微动效及直达大图预览；
2. **信息层级分明，辅助信息紧凑轻量**：
   - 下半部分清晰陈列文件名、优化体积、物理尺寸与企微上传人信息；
   - 底部配备全宽高奢极简“复制链接”按钮；
3. **智能拼接 COS / 数据万象图片缩略参数（`imageView2`）**：
   - 列表大图预览自动拼接 `imageView2/2/w/320/h/320/format/webp/q/85`，等比缩放不切边，转为极小 WebP，**节省 95% 以上预览带宽**；
   - 自动排除 `.svg` 和 `.gif` 动图；
   - 附带 `@error` 自动降级回退原图机制，零风险防挂图；
   - **严格保证交付纯净度**：点击“复制链接”与“查看大图”时，100% 保持原始纯净的无损原图 URL。
