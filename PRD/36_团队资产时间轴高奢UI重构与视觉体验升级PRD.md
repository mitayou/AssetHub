# 36_团队资产时间轴高奢UI重构与视觉体验升级PRD

## 一、需求背景与目标

团队资产库时间轴（`TimelineList.vue`）是切图交付、资产沉淀与跨职能看图复用的核心看板。针对实际体验与视觉审视中暴露的问题，进行系统性产品交互与 UI 高奢升级：
1. **修复搜索图标遮挡**：修复放大镜 SVG 因层叠上下文导致被输入框遮挡的 Bug，补足 `z-index` 与对比度；
2. **重构控制栏控件组**：将松散的“我的上传 / 全员资产”升级为 iOS 机械质感 **Segmented Control（分段滑动选择器）**，与 34px 黄金高度的舒展搜索框组成黄金控制中枢；
3. **消除预览舞台视觉噪点**：重构棋盘格底纹为柔光纯净微网格，为小尺寸切图（如 64×64）增加微阴影聚焦托盘，杜绝小图被高反差棋盘格淹没的杂乱感；
4. **重构卡片信息与操作按钮**：卡片圆角与呼吸阴影全面升级，底部“复制链接”升级为柔和轻奢胶囊按钮，加入格式标签（PNG/SVG）与系统/成员身份徽章；
5. **强化时间瀑布流叙事**：时间轴节点引入双层光晕（Halo），日期分组卡片化与徽标化，左侧渐变垂直导轨贯穿连贯。

---

## 二、详细改动设计

### 1. 顶部工具栏与控制中心升级
- **分段选择器**：`.segmented-control` 容器统筹“我的上传”与“全员资产”，激活态为纯白凸起微投影药丸底座；
- **搜索输入框**：统一为 34px 高度，左侧带精致翡翠灰放大镜图标（`z-index: 2`），右侧带 `✕` 清除按钮，聚焦微伸展动画。

### 2. 纯净画廊卡片与预览舞台
- **柔光舞台**：替代原有过于密集的深色黑白棋盘格，改用极浅的微透光棋盘底纹与内发光，小图标中心悬浮更有质感；
- **轻奢操作按钮**：复制链接按钮改用柔和微透质感（`rgba(0, 163, 79, 0.05)` 底，微边框），hover 时渐变点亮；
- **元数据微排版**：文件名单行优雅省略；增加文件类型徽标与尺寸胶囊；系统上传人规范化呈现。

### 3. 时间轴节点与日期群组
- 左侧主节点增加 `0 0 0 3px rgba(0, 163, 79, 0.16)` 外发光微晕；
- 日期标题拆分为分组徽章（“今天”/“昨天”/“归档”）与标准日期文本，视觉辨识度大幅提升。
